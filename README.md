# 나만의 일정 v2

## 추가된 기능
- 월간 달력 UI
- 일정 탭하여 수정
- 일정 길게 눌러 삭제
- 일정 알림: 10분 / 30분 / 1시간 / 1일 전
- 카카오톡 텍스트 공유 수신
- 메시지에서 `내일`, `모레`, `9월 15일`, `오후 3시` 같은 날짜/시간 자동 추출
- 카카오톡 스크린샷 공유 수신
- ML Kit 한국어 OCR로 스크린샷 텍스트 읽기
- OCR 결과에서 날짜/시간 자동 추출
- 스크린샷 앱 내부 저장

## APK 만들기
저장소에 이 프로젝트 내용을 올리면 GitHub Actions가 APK를 자동 빌드합니다.
